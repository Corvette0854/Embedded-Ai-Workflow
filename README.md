# 把今天弄懂的东西，留给下次的自己

和 AI 聊明白了，过几天却只记得“好像懂过”；项目调通了，再遇到同一个问题，又得翻一遍聊天。

用这个包，把学习和做项目时值得留下的内容整理进自己的知识库：**随手收下材料，让 AI 核对、整理和关联，留下自己的知识、项目与经验，方便复习和再次使用。**

## 留下来，是为了以后能用

- **学习后容易忘**：先看笔记开头的一小段，快速想起主线；想试着口述，再展开答案。
- **做过却记不清**：后面保留代码、排查过程、结果和依据，下次遇到问题能查细节。
- **面试前时间紧**：让 AI 按岗位要求从自己的记录里挑相关内容，复习真正做过的事和待补的知识。

知识的积累来自后来再次查用、补充和迁移；生成更多笔记本身不等于复利。

## 先看看一份笔记怎样帮助回忆

屏幕上的数值需要不断更新。有个常见的小问题：从 `12` 改成 `8` 后，旧的 `2` 还留着。

当时查清楚了，过几天却可能忘了怎么处理。笔记里留下检查方向和具体改法，下次就能直接翻到。下面几篇示例，把这个问题分别记成经验、知识和项目记录。

- [一篇经验](示范知识库/经验/屏幕数字变短后尾字符残留.md)：留下当时怎样定位和处理。
- [一篇知识](示范知识库/学习/屏幕数字变短后为什么留下旧字符.md)：用几个格子讲懂新数字与旧区域。
- [一个项目入口](示范知识库/项目/数据采集与显示.md)：知道这件事在哪条链路里。

先读经验笔记开头的“下次再遇到，先看这里”，回忆现象、判断和处理。在 Obsidian 中，口述答案、具体例子和补充说明可以用不同颜色与图标的折叠块区分，需要时点开；其他阅读器可能直接展开。详细过程在后面，相关知识和项目用链接接起来。示例里的细节可以换成自己的数据、操作和结果。

## 用自己的内容试试

直接[下载 v1.1 压缩包](https://github.com/Corvette0854/Embedded-Ai-Workflow/releases/download/v1.1/Embedded-Ai-Workflow-v1.1.zip)，解压后打开[00-先看这里](00-先看这里.md)。已经拿到文件夹，就从这个中文入口开始。

在 GitHub 上，也可以点绿色的 **Code** 按钮，再选 **Download ZIP**，取得当前文件。

熟悉 Git 的人也可以 clone；想使用某个固定版本，可以从 **Tags** 选择对应版本。几种方式取得的都是本包文件，按自己方便的方式使用即可。

把解压后的文件夹交给能读取它的 AI，说：

```text
我想用这个包建立或改善自己的知识库。请先看包里的说明，了解我的笔记习惯，带我整理一份自己的材料。
让我看到实际内容，再确定方便阅读、继续补充的位置。已有好笔记和开发习惯就沿用。
```

然后给它一段学习聊天、一份项目记录，或最近踩过的坑。还没空整理就说“只收集”；想一起处理就说“整理收集箱”；想复习就说“按这篇带我回顾”。

已经在项目对话里工作？一段排查或一个模块告一段落时，就可以让当前 AI 按个人库的规则整理值得留下的内容。先保存并核对结果，再换对话；新对话从文件读取规则和实际进度，不靠聊天记忆接续。[阶段整理与面试复习](资料/知识怎样留下来.md)。

**还没有知识库**？从自己的第一篇、收集入口和阅读入口开始。**已经在记笔记**？沿用喜欢的软件，借用有帮助的部分。约定好以后，AI 选模板、优先补原篇、归档并关联，你看自己的成品。

## 关于这个包

Embedded-Ai-Workflow 以个人知识库为主，示例偏嵌入式。你的工程和开发工具继续照常使用；需要时参考[开发中的记录建议](资料/开发协作参考.md)。

解压后也可以从[00-先看这里](00-先看这里.md)进入。AI 无法读文件时提供[接入说明](资料/AI接入说明.md)和材料即可。本包在发材料或请求整理时协助处理，没有后台整理服务；跨工具适配与持续使用效果仍待真实试用。模板、来源和[版本记录](CHANGELOG.md)在[按需资料](资料/资料导航.md)里查看。

如果你有更顺手的做法、其他方向的例子，或在使用时卡住了，欢迎[一起改进](.github/CONTRIBUTING.md)。一处更正、一份经验，都可能让下一个人更容易开始。
