# 项目示例：数据怎样从采集端来到显示屏？

比如一个设备采集到数值8，要把它送到另一端的屏幕显示。中间经过了哪些处理？如果显示不对，应该从哪里查？

## 快速恢复主线

**目标**：采集数值，传给显示端，解析后更新屏幕。

```text
传感器读数 → 准备数字文本 → 发送 → 接收缓冲
           → 解析出数值 → 格式化文字 → 更新屏幕
```

这里用数字文本举例；实际项目可以使用二进制字段，消息边界、字节序与单位按双方协议决定。

## 沿着数值8走一遍

> [!example]- 从读数到屏幕，每段分别看什么？
> 1. 采集端得到数值8，先看原始读数和换算结果是否正确。
> 2. 程序准备文本 `"8"`，发送前查看实际交给通信接口的内容。
> 3. 显示端收到字节，先看接收内容，再看解析结果是否为8。
> 4. 程序把8格式化成显示文字，最后检查屏幕上的结果。
>
> 收到字节、解析正确和显示正确是三个不同观察点，不能用其中一个代替整条链路。

如果接收与解析结果都是8，屏幕却留下旧字符，就先检查文字绘制和旧区域覆盖；如果接收内容已不对，则继续往发送与通信方向查。找最后一个正确的观察点，再缩小范围。
